GenericKanban

Control OLE de tablero Kanban, genérico e independiente de la base de datos, para aplicaciones Clarion. Construido con WebView2 y SortableJS.

Requisitos e instalación

  • .NET Framework 4.8
  • Clarion 11.0 o superior
  • WebView2 Runtime instalado en el equipo destino

Copiar el contenido de Clarion/accessory/ a la carpeta accessory de Clarion:

bin/GenericKanban.dll        → accessory\bin\
resources/GenericKanban.manifest → accessory\resources\
resources/wwwroot/           → accessory\resources\wwwroot\
Incluir KanbanWrapper.inc / KanbanWrapper.clw (en Clarion/accessory/libsrc/win/) en el proyecto Clarion. La clase KanbanWrapperClass envuelve las llamadas COM crudas para un código más limpio — es la forma recomendada de usar el control.

Conceptos básicos

El control se coloca en la ventana como un OLE control estándar. El flujo típico es:

  1. Crear el control OLE y llamar Kanban.Init(?KanbanOLE) + Kanban.RegisterEvents(?KanbanOLE, Kanban_Event) en EVENT:OpenWindow.
  2. Esperar el evento PageReady antes de asumir que el tablero está listo — aunque en la práctica los métodos llamados antes también funcionan: se encolan internamente y se ejecutan apenas la página termina de cargar.
  3. Armar columnas, tarjetas, filtros, menú contextual y estados dentro de OnPageReady.
  4. Procesar eventos entrantes (CardMoved, CardClick, etc.) con Kanban.GetEvent() en un loop, disparado por el evento posteado (Kanban_Event).
  5. Llamar Kanban.Kill() al cerrar la ventana.

Ver la sección Ejemplo completo para el patrón completo.

Orden automático por prioridad o fecha Nuevo

SetColumnSortMode define el orden inicial/por defecto de las tarjetas dentro de una columna. Se vuelve a aplicar automáticamente cuando:

  • Se agrega una tarjeta nueva a la columna (AddCard).
  • Se cambia la prioridad de una tarjeta (SetCardPriority).
  • Se cambia la fecha de vencimiento de una tarjeta (SetCardDueDate).
  • Se llama SetColumnSortMode explícitamente.
Después de cada auto-orden, el usuario puede seguir arrastrando tarjetas libremente dentro de la columna — el drag manual nunca queda bloqueado. El próximo evento de la lista de arriba vuelve a aplicar el orden automático. 
Kanban.SetCardPriority('c1', 1)      ! menor número = mayor prioridad
Kanban.SetCardPriority('c2', 3)
Kanban.SetColumnSortMode('new', 'priority')   ! c1 queda arriba de c2

Kanban.SetColumnSortMode('testing', 'date')   ! ordena por SetCardDueDate
Kanban.SetColumnSortMode('closed', 'none')    ! vuelve a orden libre (sin auto-orden)

Contraste automático de texto Nuevo

Cuando se setea un color de fondo (SetCardBackgroundColor, SetColumnHeaderColor) sin haber seteado explícitamente un color de texto, el control elige automáticamente negro o blanco según la luminancia del color de fondo, para garantizar contraste legible tanto en modo claro como en modo oscuro. Si luego se llama SetCardTextColor / SetColumnHeaderTextColor explícitamente, ese color manual siempre tiene prioridad sobre el automático. 

Kanban.SetCardBackgroundColor('c1', 0FDEDECh)  ! fondo rosado claro
                                                ! → texto negro automático
Kanban.SetCardBackgroundColor('c2', 02C3E50h)  ! fondo azul oscuro
                                                ! → texto blanco automático
Kanban.SetCardTextColor('c1', 0800000h)        ! override manual: siempre gana

Idioma (ES / EN) Nuevo

MétodoDescripción
SetLanguage(lang)Idioma del chrome del control: "en" o "es" (por defecto "en")

Traduce los textos propios del control: encabezados de la vista tabla, panel de filtros (título, "Limpiar todo", buscador), badge de VENCIDA, prefijo de fecha de vencimiento y el selector Tablero/Tabla.

No traduce el contenido de las tarjetas. Títulos, cuerpo, etiquetas, responsable, etc. son texto libre que ingresa la aplicación Clarion — si necesita mostrarlos en ambos idiomas, la aplicación debe pasar el texto ya traducido a los setters correspondientes. 
Kanban.SetLanguage('es')   ! chrome del control en castellano
Kanban.SetLanguage('en')   ! de vuelta a inglés (también el valor por defecto)

Guardar / restaurar estado Nuevo

MétodoDescripción
GetBoardState()Devuelve un string JSON con toda la configuración a nivel tablero
SetBoardState(json)Restaura la configuración desde un JSON producido por GetBoardState()

Cubre: modo oscuro, solo-lectura, ancho de columna, tamaño de fuente, idioma, título del tablero (texto y colores), visibilidad por columna y modo de auto-orden por columna. No incluye columnas ni tarjetas — esas las gestiona la aplicación Clarion, que normalmente las vuelve a crear al abrir la ventana. 

! Esquema JSON devuelto por GetBoardState()
{
  "version": 1,
  "darkMode": true,
  "readOnly": false,
  "columnWidth": 260,
  "fontSize": 14,
  "language": "es",
  "boardTitle": "Mi Tablero",
  "boardTitleColorBg": -1,
  "boardTitleColorText": -1,
  "columnVisibility": { "new": true, "closed": false },
  "columnSortModes": { "new": "priority" }
}

Uso típico: guardar el JSON en una tabla o archivo de configuración del usuario, y restaurarlo al reabrir la ventana.

! Al cerrar / guardar preferencias del usuario
UserPrefs.KanbanState = Kanban.GetBoardState()

! Al reabrir la ventana, ANTES o DESPUÉS de PageReady (ambos casos funcionan:
! las llamadas se encolan internamente hasta que la página esté lista)
Kanban.SetBoardState(UserPrefs.KanbanState)
El JSON puede ser largo si hay muchas columnas. El wrapper Clarion reserva STRING(8000) para el valor de retorno de GetBoardState() — en tableros con una cantidad muy grande de columnas, verificar que el string no se trunque.

Filtrar por usuario/responsable Nuevo

SetAssigneeFilter es un atajo de un solo llamado para el caso de uso más común de "Mis tareas" — no requiere pre-registrar cada responsable como ítem de filtro (a diferencia del panel de filtros genérico de arriba). Se combina con AND junto a los filtros del panel y la búsqueda de texto: una tarjeta solo se muestra si pasa todas las condiciones activas a la vez.

Mientras el filtro está en modo "un solo usuario", el nombre del responsable se oculta en la tarjeta (es redundante, ya que todas las visibles son de esa persona). Al pasar a "todos los usuarios" (string vacío), el nombre vuelve a mostrarse automáticamente en cada tarjeta que tenga un responsable asignado. 
! Modo "Mis tareas" — solo tarjetas de 'Sarah', sin mostrar su nombre en cada tarjeta
Kanban.SetAssigneeFilter('Sarah')

! Volver a "todos los usuarios" — el nombre del responsable reaparece en cada tarjeta
Kanban.SetAssigneeFilter('')

Sistema de estados

MétodoDescripción
SetStatusTitle(title)Nombre visible del grupo de estados
AddStatusOption(optionId, label, color)Registra un valor de estado posible
BuildFilterFromStatus()Crea un grupo de filtro a partir de los estados registrados
BuildMenuFromStatus(parentId)Crea un radio-grupo de menú contextual a partir de los estados registrados
El sistema de estados es un atajo: une en un solo concepto (SetCardStatus) la barra de color de la tarjeta, el radio-grupo del menú contextual y el filtro — evita mantener esos tres mecanismos sincronizados manualmente cuando representan el mismo valor (por ejemplo, severidad o prioridad de un ticket).

Referencia de eventos

EventoParámetrosDescripción
CardMovedcardId, fromColumnId, toColumnIdUna tarjeta cambió de columna (drag o MoveCard)
PageReady—El tablero terminó de inicializarse y está listo para recibir llamadas
ContextMenuSelectedcardId, itemIdSe seleccionó un ítem del menú contextual
CardClickcardIdClick simple confirmado (debounce de 300 ms, mutuamente excluyente con el doble click)
CardDoubleClickcardIdDoble click (cancela el click simple pendiente)
CardRightClickcardIdClick derecho, antes de mostrar el menú contextual — permite ajustar el menú dinámicamente por tarjeta antes de llamar ShowContextMenu(cardId)

En Clarion, los eventos se consumen con un loop sobre Kanban.GetEvent(), disparado por el evento OLE posteado (ver ejemplo completo). Kanban.EventName, Kanban.Parm1/2/3 traen el nombre del evento y sus parámetros.

Ejemplo completo

Patrón mínimo de uso (ver HandCodeExample/HandCodeExample.clw para el ejemplo completo del repositorio):

Window      WINDOW('Demo'),AT(,,741,397),GRAY,IMM,SYSTEM
              OLE,AT(2,2,615,374),USE(?KanbanOLE)
              END
            END
Kanban_Event    EQUATE(Event:User+2000+?KanbanOLE)

Kanban      Class(KanbanWrapperClass)
Init                  PROCEDURE(LONG pCtrl),VIRTUAL
OnPageReady           PROCEDURE(),VIRTUAL
OnCardMoved           PROCEDURE(STRING pCardId, STRING pFromColumn, STRING pToColumn),VIRTUAL
            End

  CODE
  OPEN(Window)
  ACCEPT
    CASE EVENT()
    OF EVENT:OpenWindow
      ?KanbanOLE{PROP:Create} = 'GenericKanban.GenericKanbanControl'
      Kanban.Init(?KanbanOLE)
      Kanban.RegisterEvents(?KanbanOLE, Kanban_Event)
    OF EVENT:CloseWindow
      Kanban.Kill()
      BREAK
    OF Kanban_Event
      LOOP WHILE Kanban.GetEvent()
        CASE Kanban.EventName
        OF 'PageReady';      Kanban.OnPageReady()
        OF 'CardMoved';      Kanban.OnCardMoved(Kanban.Parm1, Kanban.Parm2, Kanban.Parm3)
        END
      END
    END
  END
  CLOSE(Window)

Kanban.Init         PROCEDURE(LONG pCtrl)
  CODE
  PARENT.Init(pCtrl)

Kanban.OnPageReady  PROCEDURE()
  CODE
  PARENT.OnPageReady()
  SELF.AddColumn('new', 'Nuevo', COLOR:Blue)
  SELF.AddColumn('done', 'Terminado', COLOR:Green)
  SELF.AddCard('c1', 'new', 'Primera tarjeta', 'Descripción de ejemplo')
  SELF.SetDarkMode(1)
  SELF.SetLanguage('es')

Kanban.OnCardMoved  PROCEDURE(STRING pCardId, STRING pFromColumn, STRING pToColumn)
  CODE
  ! Reaccionar al movimiento (ej. actualizar un campo de estado en la base de datos)

Novedades de esta versión

Resumen de las capacidades agregadas — todas retrocompatibles, no modifican el comportamiento de ningún método existente:

Ocultar columnas Nuevo

SetColumnVisible(columnId, visible) — oculta/muestra una columna conservando sus tarjetas.

Idioma ES/EN Nuevo

SetLanguage(lang) — traduce el chrome del control, no el contenido de las tarjetas.

Orden por prioridad/fecha Nuevo

SetCardPriority + SetColumnSortMode — auto-orden como valor por defecto, con drag manual libre después.

Tipografía y contraste Nuevo

SetFontSize(px) + contraste automático de texto negro/blanco según el color de fondo.

Guardar / restaurar estado Nuevo

GetBoardState() / SetBoardState(json) — persiste modo oscuro, solo-lectura, ancho, tipografía, idioma y más.

Filtro por usuario/responsable Nuevo

SetAssigneeFilter(assignee) — modo "Mis tareas" de un solo llamado; oculta el nombre en la tarjeta mientras el filtro está activo.

Pendiente para 2ª etapa

Ancho de columna dinámico (dividir el ancho disponible del control entre las columnas y redimensionar) queda para una etapa posterior.
