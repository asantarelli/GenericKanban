GenericKanban

A generic, database-agnostic Kanban board OLE control for Clarion applications. Built with WebView2 and SortableJS.

Requirements & installation

  • .NET Framework 4.8
  • Clarion 11.0 or later
  • WebView2 Runtime installed on the target machine

Copy the contents of Clarion/accessory/ into your Clarion accessory folder:

bin/GenericKanban.dll        → accessory\bin\
resources/GenericKanban.manifest → accessory\resources\
resources/wwwroot/           → accessory\resources\wwwroot\
Include KanbanWrapper.inc / KanbanWrapper.clw (in Clarion/accessory/libsrc/win/) in your Clarion project. The KanbanWrapperClass wraps the raw COM calls for cleaner code — this is the recommended way to use the control.

Basic concepts

The control is dropped onto a window like any standard OLE control. The typical flow is:

  1. Create the OLE control and call Kanban.Init(?KanbanOLE) + Kanban.RegisterEvents(?KanbanOLE, Kanban_Event) in EVENT:OpenWindow.
  2. Wait for the PageReady event before assuming the board is ready — although in practice methods called earlier also work: they are queued internally and executed as soon as the page finishes loading.
  3. Build columns, cards, filters, context menu and status options inside OnPageReady.
  4. Process incoming events (CardMoved, CardClick, etc.) with a Kanban.GetEvent() loop, triggered by the posted event (Kanban_Event).
  5. Call Kanban.Kill() when the window closes.

See the Full example section for the complete pattern.

SetColumnSortMode(columnId, mode) NewAuto-sorts the column by "priority" or "date" (or "none") — see details below

Automatic sort by priority or date New

SetColumnSortMode sets the initial/default order of the cards inside a column. It is re-applied automatically when:

  • A new card is added to the column (AddCard).
  • A card's priority changes (SetCardPriority).
  • A card's due date changes (SetCardDueDate).
  • SetColumnSortMode is called explicitly.
After each auto-sort pass, the user can still freely drag cards within the column — manual dragging is never blocked. The next event from the list above re-applies the automatic order. 
Kanban.SetCardPriority('c1', 1)      ! lower number = higher priority
Kanban.SetCardPriority('c2', 3)
Kanban.SetColumnSortMode('new', 'priority')   ! c1 ends up above c2

Kanban.SetColumnSortMode('testing', 'date')   ! sorts by SetCardDueDate
Kanban.SetColumnSortMode('closed', 'none')    ! back to free order (no auto-sort)

Board appearance

Automatic text contrast New

When a background colour is set (SetCardBackgroundColor, SetColumnHeaderColor) without an explicit text colour having been set, the control automatically picks black or white text based on the background's luminance, to guarantee readable contrast in both light and dark mode. If SetCardTextColor / SetColumnHeaderTextColor is later called explicitly, that manual colour always takes priority over the automatic one. 

Kanban.SetCardBackgroundColor('c1', 0FDEDECh)  ! light pink background
                                                ! → automatic black text
Kanban.SetCardBackgroundColor('c2', 02C3E50h)  ! dark navy background
                                                ! → automatic white text
Kanban.SetCardTextColor('c1', 0800000h)        ! manual override: always wins

Language (ES / EN) New

MethodDescription
SetLanguage(lang)Control chrome language: "en" or "es" (default "en")

Translates the control's own chrome text: table-view headers, filter panel (heading, "Clear all", search box), the OVERDUE badge, the due-date prefix, and the Board/Table view switcher.

Does not translate card content. Titles, body, tags, assignee, etc. are free text entered by the Clarion application — if you need to show them in both languages, the application must pass already-translated text to the corresponding setters. 
Kanban.SetLanguage('es')   ! control chrome in Spanish
Kanban.SetLanguage('en')   ! back to English (also the default value)

Save / restore state New

MethodDescription
GetBoardState()Returns a JSON string with all board-level settings
SetBoardState(json)Restores settings from a JSON string produced by GetBoardState()

Covers: dark mode, read-only, column width, font size, language, board title (text and colours), per-column visibility and per-column auto-sort mode. Does not include columns or cards — those are managed by the Clarion application, which normally re-creates them when the window opens. 

! JSON schema returned by GetBoardState()
{
  "version": 1,
  "darkMode": true,
  "readOnly": false,
  "columnWidth": 260,
  "fontSize": 14,
  "language": "en",
  "boardTitle": "My Board",
  "boardTitleColorBg": -1,
  "boardTitleColorText": -1,
  "columnVisibility": { "new": true, "closed": false },
  "columnSortModes": { "new": "priority" }
}

Typical use: save the JSON to a user-preferences table or file, and restore it when the window reopens.

! When closing / saving user preferences
UserPrefs.KanbanState = Kanban.GetBoardState()

! When reopening the window, BEFORE or AFTER PageReady (both work:
! calls are queued internally until the page is ready)
Kanban.SetBoardState(UserPrefs.KanbanState)
The JSON can be long if there are many columns. The Clarion wrapper reserves STRING(8000) for the GetBoardState() return value — on boards with an unusually large number of columns, verify the string is not truncated.

Context menu

MethodDescription
ClearContextMenu()Clears all context menu items
AddContextMenuItem(parentId, itemId, label)Adds a clickable menu item
AddContextMenuSub(parentId, subId, label)Adds a sub-menu
AddContextMenuSep(parentId)Adds a separator

Passing parentId='' adds the item at the root level of the menu; passing a submenu/group ID nests it inside. The CardRightClick event fires before the menu is shown, letting you enable/disable items dynamically per card before calling ShowContextMenu(cardId).

Filters

MethodDescription
ClearFilters()Clears all filter groups and items
AddFilterGroup(groupId, title)Adds a filter group section
AddFilterItem(groupId, itemId, label, color)Adds a filter option with a colour swatch
SetTextSearchEnabled(enabled)Shows (1) or hides (0) the text search box
SetAssigneeFilter(assignee) NewShows only cards whose assignee (SetCardAssignee) matches exactly; an empty string shows every assignee again

Filter by user/assignee New

SetAssigneeFilter is a one-call shortcut for the common "My Tasks" use case — it does not require pre-registering every assignee as a filter item (unlike the generic filter panel above). It composes with AND alongside the filter panel and text search: a card is only shown if it passes every active condition at once.

While the filter is in "single assignee" mode, the assignee's name is hidden on the card (redundant, since every visible card already belongs to them). Switching back to "all assignees" (empty string) automatically brings the name back on every card that has one. 
! "My Tasks" mode — only Sarah's cards, without repeating her name on every card
Kanban.SetAssigneeFilter('Sarah')

! Back to "all assignees" — the assignee name reappears on every card
Kanban.SetAssigneeFilter('')

Status system

MethodDescription
SetStatusTitle(title)Display name for the status group
AddStatusOption(optionId, label, color)Registers a possible status value
BuildFilterFromStatus()Creates a filter group from the registered status options
BuildMenuFromStatus(parentId)Creates a context menu radio group from the registered status options
The status system is a shortcut: it ties together in a single concept (SetCardStatus) the card's colour bar, the context menu radio group, and the filter — avoiding manually keeping those three mechanisms in sync when they represent the same value (e.g. a ticket's severity or priority).

Event reference

In Clarion, events are consumed with a loop over Kanban.GetEvent(), triggered by the posted OLE event (see the full example). Kanban.EventName, Kanban.Parm1/2/3 carry the event name and its parameters.

Full example

Minimal usage pattern (see HandCodeExample/HandCodeExample.clw for the full repository example):

Window      WINDOW('Demo'),AT(,,741,397),GRAY,IMM,SYSTEM
              OLE,AT(2,2,615,374),USE(?KanbanOLE)
              END
            END
Kanban_Event    EQUATE(Event:User+2000+?KanbanOLE)

Kanban      Class(KanbanWrapperClass)
Init                  PROCEDURE(LONG pCtrl),VIRTUAL
OnPageReady           PROCEDURE(),VIRTUAL
OnCardMoved           PROCEDURE(STRING pCardId, STRING pFromColumn, STRING pToColumn),VIRTUAL
            End

  CODE
  OPEN(Window)
  ACCEPT
    CASE EVENT()
    OF EVENT:OpenWindow
      ?KanbanOLE{PROP:Create} = 'GenericKanban.GenericKanbanControl'
      Kanban.Init(?KanbanOLE)
      Kanban.RegisterEvents(?KanbanOLE, Kanban_Event)
    OF EVENT:CloseWindow
      Kanban.Kill()
      BREAK
    OF Kanban_Event
      LOOP WHILE Kanban.GetEvent()
        CASE Kanban.EventName
        OF 'PageReady';      Kanban.OnPageReady()
        OF 'CardMoved';      Kanban.OnCardMoved(Kanban.Parm1, Kanban.Parm2, Kanban.Parm3)
        END
      END
    END
  END
  CLOSE(Window)

Kanban.Init         PROCEDURE(LONG pCtrl)
  CODE
  PARENT.Init(pCtrl)

Kanban.OnPageReady  PROCEDURE()
  CODE
  PARENT.OnPageReady()
  SELF.AddColumn('new', 'New', COLOR:Blue)
  SELF.AddColumn('done', 'Done', COLOR:Green)
  SELF.AddCard('c1', 'new', 'First card', 'Sample description')
  SELF.SetDarkMode(1)
  SELF.SetLanguage('en')

Kanban.OnCardMoved  PROCEDURE(STRING pCardId, STRING pFromColumn, STRING pToColumn)
  CODE
  ! React to the move (e.g. update a status field in the database)

What's new in this version

Summary of the added capabilities — all backward-compatible, none change the behaviour of any existing method:

Hide columns New

SetColumnVisible(columnId, visible) — hides/shows a column while keeping its cards.

ES/EN language New

SetLanguage(lang) — translates the control chrome, not card content.

Sort by priority/date New

SetCardPriority + SetColumnSortMode — auto-sort as the default order, with free manual dragging afterward.

Typography & contrast New

SetFontSize(px) + automatic black/white text contrast based on background colour.

Save / restore state New

GetBoardState() / SetBoardState(json) — persists dark mode, read-only, width, typography, language and more.

Filter by user/assignee New

SetAssigneeFilter(assignee) — one-call "My Tasks" mode; hides the name on the card while the filter is active.

Planned for a later stage

Dynamic column width (dividing the control's available width across columns and resizing) is left for a future stage.
